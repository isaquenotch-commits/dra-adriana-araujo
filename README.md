# Adriana Araujo — Fisioterapia · Acupuntura · Estética

Site institucional da Dra. Adriana Araujo, construído com Vite, React, Tailwind CSS, Motion, Lenis e React Three Fiber.

**Site no ar:** https://isaquenotch-commits.github.io/dra-adriana-araujo/

## Rodar localmente

```bash
npm install
npm run dev
```

## Publicação

Cada push na branch `main` gera o build e publica no GitHub Pages pelo workflow em `.github/workflows/deploy.yml`.
